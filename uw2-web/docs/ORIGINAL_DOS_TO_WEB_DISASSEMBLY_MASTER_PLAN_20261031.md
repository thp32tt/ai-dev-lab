# 대항해시대 II 독립 웹게임 포팅 마스터 계획 — 현행 정책

**2026-11-03 사용자 최우선 확정.** 파일명은 과거 링크 및 자동개발 호환용으로 유지한다. 이전 2026-10-31~11-02 P0/P1/P3/8086/IR/MZ/EMS/DOS 실행 계획은 Git 이력의 과거 기록이며 신규 자동개발 작업 대상으로 **폐기**한다. 웹게임의 실행 경로는 web/index.html → web/app.js → 직접 작성한 JS/Canvas 게임 코드다. DOSBox/8086 하이브리드 폴백은 금지한다.

## 웹게임의 실제 완료 목표
1. **새 게임 여섯 주인공:** 실제 원본 데이터에 근거한 초기 인물·항구·선단·돈·날짜·이벤트를 JS 상태로 생성하여 항구 보행/원본 UI/웹 체크포인트까지 연결한다. 기존 저장 슬롯을 신규게임 생성으로 가장하거나 근거 없는 초기 값을 채우지 않는다.
2. **항구 플레이:** NPC 대화, 건물 진입·퇴장, 주점·시장·은행·아이템·선단·출항 준비를 키보드·마우스·터치로 처리한다. 상태·시간·돈·선원/물자 변경은 원자적이다.
3. **항해·기항:** 원본 해도·타일·선박·바람·해류·항해 20분 틱/월말 은행과 경계 조건을 실제 브라우저에서 검증하고 항구→해상→항구 왕복 플레이를 완성한다. 2026-11-03 해상 길게 누르기 코드는 CI 통과, 실브라우저 사용자 확인은 UNTESTED.
4. **전투·시나리오·엔딩:** 원본 근거가 확인된 규칙과 그래픽으로 네이티브 게임 UI·상태를 통합한다. 추측한 게임 기능·상태는 HOLD.
5. **저장/재개:** 원본 DOS 저장은 읽기 전용이고, 원본 세이브 슬롯과 별도 브라우저 체크포인트의 항구·해상·날짜·선단 상태가 재시작 후 정확히 복원돼야 한다.
6. **화면·소리·모바일:** 한국어 폰트, GRAPH/OPGRAPH/CHAR/LS11 원본 그래픽/색상/오디오를 실제 Canvas/브라우저 입력에서 검증한다.

## 절대 금지 대상
- CPU/8086 실행기·원본 CALL 명령체인·DOS INT21·EMS INT67·MZ/PSP/IVT·가상 BIOS/VGA/OPL/PIC/PIT·FMDRV/KOEI DOS 부팅을 신규 구현, 기존 기능 확장, 신규 테스트/probe 추가하거나 다음 과제로 선정하지 않는다.
- 기존 에뮬레이터 소스는 읽기 전용 동결. 원본 분석은 특정 웹게임 입력/화면/규칙 확인이 필요할 때 짧게 근거를 읽는 용도로만 이용하며 웹 배포 기능 수정으로 즉시 연결한다. CPU 실행 명령 수·DOS 인터럽트 통과·단독 probe는 **게임 성과 0건**.
- GitHub에 저작권 있는 원본 파일을 업로드하지 않고, 미확정 스토리·밸런스·원작 캐릭터를 상상해 구현하지 않는다.

## 자동개발 C 슬롯
- 컨트롤러 입력은 '웹포팅 개발 계속진행해' 한 줄이다. 매번 GitHub HEAD → uw2-web/AGENTS.md → **이 파일** → web/app.js 실제 브라우저 게임 경로를 확인한다. 이전 대화나 과거 마스터의 '다음 DOS/8086 실행' 제안은 무효다.
- 하나의 **실제 게임 사용자 기능**을 작업 대상으로 잡아 관련 소스·상태·화면·회귀를 함께 완결한다. 가급적 약 20분 이상 실개발을 목표로 하지만 인위적인 대기·문서만 반복·사소한 작업 단위로 완료 선언을 금지한다. CI 반복·같은 SHA 재검증도 금지한다.
- GitHub SSOT로 실제 web/ 배포 코드와 직접 관련된 테스트를 변경하고 정확 SHA Actions 결과를 확인한다. 도구·문서·테스트 단독 작업은 성과가 아니다. N100은 사용자 원본 데이터 확인/Firefox 브라우저 실기 때만 보조로 사용한다.
- GitHub CI enforce-webport-scope.mjs는 에뮬레이터 변경을 차단하고 웹 게임 코드 + 테스트 없는 기능 커밋을 거부한다. 사용자의 별도 명시 지시 없이는 자동개발 정책 예외가 없다.
