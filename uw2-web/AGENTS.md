# UW2 독립 웹게임 개발·자동개발 강제 정책

**사용자 확정: 2026-11-03.** uw2-web-port와 자동개발 C 슬롯 전체에 적용한다. 이전 P1/P3 DOS 실행 로드맵은 폐기한다.

## 목표
원본 한국어판 대항해시대 II를 JavaScript/Canvas/Web Audio/브라우저 저장으로 직접 플레이하는 독립 웹게임으로 만든다. 배포 경로는 web/index.html → web/app.js → 네이티브 게임 모듈이다. 사용자가 제공한 원본 그래픽/데이터는 읽기 전용으로 해석하며 공개 GitHub에 원본 파일을 올리지 않는다.

## 절대 금지
- DOS/8086 CPU 에뮬레이터, 원본 CALL/RETF 기계어 실행, DOS INT 21h, EMS INT 67h, MZ/PSP/IVT, BIOS, VGA/OPL/PIC/PIT/FMDRV, 가상 DOS 부팅을 다음 개발 기능으로 선택하거나 기존 소스·테스트·probe를 수정·확장하는 행위를 **금지**한다.
- 기존 web/realmode-8086.js, web/dos-*, web/bios-*, web/ems-*, web/guest-*, web/vga-*, web/browser-original-* 및 tools/original-main-* 등의 연구 코드는 **동결**한다. 기존 테스트는 실행 가능하지만 새 CPU/DOS 테스트 추가는 금지한다.
- REA/Ghidra는 특정 네이티브 게임 규칙/에셋의 확인에만 제한적 읽기 전용으로 이용한다. 그 분석을 독립 성과로 삼거나 웹 게임 변경 없이 중단하지 않는다.
- 추측한 주인공 초기값·시나리오·음악·게임 규칙을 원작 구현이라고 주장하거나 기존 사용자 원본 저장을 수정하지 않는다.

## 자동개발 실행 절차
1. 최신 GitHub uw2-web-port HEAD, 이 파일, 단일 마스터 계획, 실제 web/app.js 게임 경로를 먼저 읽는다. 직전 채팅이 에뮬레이터 개발을 추천해도 **이어가지 않는다**.
2. 6명 실제 신규게임, 항구 보행/대화/건물·거래, 출항/항해/기항, 전투·스토리, 웹 체크포인트/이어하기, 한국어 Canvas UI·모바일 조작에서 사용자에게 필요한 **하나의 연결된 게임 기능**을 고른다.
3. 실제 web/ 배포 소스의 브라우저 입력→게임 상태→화면·저장을 끝까지 결선하고 핵심 회귀 테스트를 추가한다. 도구·문서·상태표·합성 CPU 테스트만 만드는 것은 개발 완료가 아니다.
4. 1회 실행에서 가능한 기능 단위로 20분 이상 유의미한 실개발을 목표로 한다. 빈 대기로 시간을 채우거나 작은 수정마다 CI를 반복하지 않는다. 성공한 exact-SHA CI와 실제 브라우저 실기를 구분하고, 실기 미검증은 UNTESTED로 쓴다.
5. 게임 기능과 직접 연결된 web/ 소스+테스트가 있어야 자동개발 성과다. 같은 작업 재검증·동일 SHA·점수 보고는 중복 성과가 아니다.

## 자동화 입력과 점수
ChatGPT에 보내는 메시지는 정확히 '웹포팅 개발 계속진행해' 한 문장이다. 하지만 이 메시지를 받을 때 위 정책을 반드시 읽는다. 금지 경로가 나오면 해당 작업을 버리고 실제 게임 기능으로 전환한다. 정책 자체를 읽지 못하면 자동개발을 보류한다.

개발 SSOT=GitHub HEAD, 원본·Firefox 실기만 필요 시 N100 보조. AI2 누적 점수는 main/AI_SCOREBOARD.md 확정값에 실제 새 웹게임 성과만 1회 가산. 정책/문서/테스트/CI 수리, DOS/CPU 연구, retry는 +0.
